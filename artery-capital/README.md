# Artery Capital

Expert investment solutions tailored to your financial goals. Build your wealth through strategic investments.

## Features

- 🏠 **Modern Website**: Clean, professional landing page with hero section
- 📝 **Application Portal**: Comprehensive investment application form
- 🎨 **Beautiful UI**: Built with React and Tailwind CSS
- 🔀 **Seamless Navigation**: React Router for smooth page transitions
- 📱 **Responsive Design**: Optimized for all devices
- 🚀 **Fast Performance**: Optimized for speed and user experience

## Tech Stack

- **React 18.2** - Modern UI library
- **React Router 6** - Client-side routing
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Beautiful icon library
- **Vercel** - Deployment platform

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm start
```

Runs the app in development mode at [http://localhost:3000](http://localhost:3000)

### Build

```bash
npm run build
```

Builds the app for production to the `build` folder.
